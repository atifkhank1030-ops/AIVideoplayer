# AI Video Player for Android (Media3 ExoPlayer)

## Quick Start
1. Open Android Studio (Ladybug 2024.2+ or Koala).
2. Choose **File > Open** and select this extracted project folder.
3. Wait for Gradle Sync to complete.
4. Connect an Android phone with **USB Debugging** enabled (or start an Android Emulator).
5. Click **Run 'app' (Shift+F10)** to install and launch on your phone.

## Build Standalone APK
- Run `./gradlew assembleDebug` in the terminal.
- Your debug APK will be located at: `app/build/outputs/apk/debug/app-debug.apk`
- Copy this file to any Android phone and install it directly!
